Legend

TRAINED / PENDING
Whether that session has been logged yet this program week. Weeks are program weeks, not calendar days — sessions land whenever they land.
Driver lifts
Highlighted rows with the orange edge: Squat, Bench, Deadlift, OHP, Weighted Pull-Up. These carry the block; everything else supports them.
F
That exercise's last set is taken to failure.
+5 → 215
The lift earned an increase — the load moves up by that much on its next exposure.
HELD
Load stays where it is; reps go up first, weight follows once the top of the range is owned on every set.
RESET · REBASED
The load dropped back to a weight that can be completed cleanly (RESET) or was re-anchored to what was actually being lifted (REBASED).
SUBSTITUTED · not logged
A different exercise was done in its place, or the lift never happened — no progression applied either way.
Rx
The prescribed load and set×rep target for this week. Dumbbell loads are total across both hands; pull-up loads are added weight.
e1RM
Estimated one-rep max from the best working set — the number to watch across a meso.
W5 · deload
Week five of every meso is a deload: same movements, light loads, then the next meso starts fresh.

Legend

TRAINED / PENDING
Whether that session has been logged yet this program week. Sessions land whenever they land — the week advances on work done, not on the calendar.
Anchors
Highlighted rows: Hip Thrust and Smith Squat. These two decide whether the block is working; everything else is support.
F
That exercise's last set is taken to failure.
Every set at the top of the range → weight up
Hit the top number on every set — including the F set — and the load goes up next time. Miss it on one set and the weight stays put until it's owned.
Overshoot jumps double
Blow past the top of the range on every set and the load jumps twice the normal step — that weight was too easy to inch up.
Weight is the only lever
Sets and rep ranges stay fixed. The only thing that changes week to week is the load on the bar or the stack.
/ leg
Unilateral — that set count and load is per leg, done on both.
Rx
The prescribed load and set×rep target for this week.
W5 · deload
Week five of every meso is a deload: same movements, light loads, then the next meso starts fresh.
