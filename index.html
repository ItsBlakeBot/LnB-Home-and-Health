Legend

Top set + back-offs
One heaviest set of the day taken in the target range, then the listed back-off sets at a fixed percentage below it. Clear the top set inside its range on every prescribed set and the top load steps up.
Double progression
Accessories hold their load and climb reps to the top of the range first. Once every set hits the top of the range, the load steps up and the reps reset to the bottom.
Readiness — GREEN / YELLOW / RED
Called at the top of the workout note. GREEN runs the session as written. YELLOW drops sprints and max jumps and cuts one back-off set. RED removes heavy and explosive work. A YELLOW or RED session is never penalised with a hold or a reset.
Rotation clock
Time runs in rotations, not weeks. A rotation is Lower A → Upper A → Lower B → Upper B, with Zone 2 + Armor and the Norwegian 4×4 floating anywhere inside it. The rotation advances when the four lift days are done, in any order and on any schedule.

  • Romanian Deadlift, Bulgarian Split Squat and loaded Standing Calf Raise are first exposures — calibrate on the first log and rebase upward from what the set actually shows.
  • Repeated lifts run on separate tracks: the heavy and moderate Hip Thrust, the A and B Hip Abduction, and the A and B Leg Extension each earn their own load. Never carry a load across.

  • Smith Squat is deep below parallel every rep. A deep 45° leg press stands in only if the hips stay deep with no pelvis roll.
  • No Hip Abduction machine at one gym — standing single-leg plate abduction stands in, and its load never transfers to the machine track.

Legend

Double progression
Hold the load and add reps until every set reaches the top of the range. Then the load steps up and the reps reset to the bottom of the range.
F — failure set
The last set of that exercise is taken to technical failure. Reps past the top of the range on a failure set still count toward earning the next load.
Separate tracks
Lifts that appear on both days progress independently. Heavy and moderate Hip Thrust, A and B Hip Abduction, and A and B Leg Extension each hold their own load and range.
Week and meso clock
A mesocycle is five weeks: four working weeks and a deload. A week advances when both sessions are trained, in any order and on any schedule.
Deload
Week 5 keeps the same movements, drops the failure sets and cuts volume to roughly 60% so the next mesocycle starts fresh.
